GET /api/places/search/

Recherche de lieux à La Réunion via des APIs publiques (proxy Django). Utilisé par la barre de recherche de la sidebar.

Paramètres

ParamètreTypeDescription
qstringTexte recherché (min. 2 caractères)
typestringall, school, pickup, delivery, depot, stop
limitintNombre max de résultats (défaut 8, max 15)

Exemple

curl "http://localhost:8000/api/places/search/?q=mondon&type=school&limit=5"

Réponse

{
  "results": [
    {
      "id": "school-0-École Raymond Mondon",
      "label": "École Raymond Mondon",
      "subtitle": "École, 71 Rue Alexis de Villeneuve, Saint-Denis, 97400",
      "type": "school",
      "lat": -20.8725,
      "lng": 55.452,
      "source": "education"
    }
  ]
}

Sources : Éducation nationale (écoles), Géoplateforme IGN (adresses), Photon/OSM (arrêts, dépôts).

POST /api/route/solve/

Résout un problème de tournée et retourne l'itinéraire optimisé.

Content-Type application/json   CSRF Requis (header X-CSRFToken)

Corps de la requête

ChampTypeRequisDescription
problem_typestringNontsp ou pdp (défaut: tsp)
pointsarrayOuiListe de points (min. 2)
points[].idintOuiIdentifiant unique
points[].latfloatOuiLatitude WGS84
points[].lngfloatOuiLongitude WGS84
points[].typestringNondepot, pickup, delivery, school, stop
num_vehiclesintNonNombre de véhicules (défaut: 1)
depot_indexintNonIndex du dépôt dans points (défaut: 0)
pickups_deliveriesarrayPDPPaires [[pickup_idx, delivery_idx], ...]
max_distanceintNonDistance max par véhicule en m (défaut: 1000000)
vehicle_capacitiesint[]NonCapacité par véhicule (places)
use_time_windowsboolNonActive les fenêtres horaires
average_speed_kmhfloatNonVitesse pour convertir distance → temps (défaut: 30)
use_road_routingboolNonOSRM si true (défaut: true)
points[].demandintNonÉlèves au ramassage
points[].school_idintNonID de l'école associée (UI)
points[].time_window_startintNonDébut créneau en minutes (ex: 420 = 07:00)
points[].time_window_endintNonFin créneau en minutes

Exemple TSP

{
  "problem_type": "tsp",
  "num_vehicles": 1,
  "depot_index": 0,
  "points": [
    {"id": 0, "lat": -20.8789, "lng": 55.4481, "type": "depot", "label": "Dépôt"},
    {"id": 1, "lat": -20.8795, "lng": 55.4490, "type": "stop", "label": "A"},
    {"id": 2, "lat": -20.8800, "lng": 55.4475, "type": "stop", "label": "B"}
  ]
}

Exemple Pickup & Delivery

{
  "problem_type": "pdp",
  "depot_index": 0,
  "pickups_deliveries": [[1, 2], [3, 4]],
  "points": [
    {"id": 0, "lat": -20.8789, "lng": 55.4481, "type": "depot"},
