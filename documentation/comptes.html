Comptes & historique

Parcours

  1. Visiteur sur la landing page (/)
  2. Inscription ou connexion
  3. Accès à l'application (/app/)
  4. Chaque calcul d'itinéraire est enregistré dans l'historique

Formulaires

  • Messages d'erreur et de succès visibles (alertes colorées)
  • Validation par champ (bordure rouge / verte)
  • Bouton afficher / masquer le mot de passe
  • Spinner au envoi (évite les double-clics)
  • Validateurs Django : longueur, mots de passe courants, similarité au nom d'utilisateur

Historique des itinéraires

Lorsqu'un utilisateur connecté clique sur Calculer l'itinéraire, une entrée RouteHistory est créée en base avec :

  • Points et configuration
  • Résultat complet (sans les grosses matrices distance/temps)
  • Résumé (distance, durée, arrêts…)

Dans l'onglet Historique du panneau flottant :

  • ↺ Recharger — restaure points, config et résultat sur la carte
  • 🗑 Supprimer — retire l'entrée

E-mail (mot de passe oublié)

En développement, le lien de réinitialisation s'affiche dans la console Django.

En production, configurez SMTP dans .env :

EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp.example.com
EMAIL_PORT=587
EMAIL_HOST_USER=...
EMAIL_HOST_PASSWORD=...
EMAIL_USE_TLS=true
DEFAULT_FROM_EMAIL=noreply@votredomaine.fr

Admin Django

Via /admin/ après createsuperuser :

  • Lieux de référence (CatalogPoint) — alimentent la recherche
  • Tournées enregistrées (SavedScenario)
  • Historique (RouteHistory)
