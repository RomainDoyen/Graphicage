Guide utilisateur

De la landing page au calcul d'itinéraire optimisé.

Avant l'application

  1. Ouvrez http://localhost:8000/ (landing page)
  2. Cliquez Créer un compte ou Connexion
  3. Accédez à l'application via Ouvrir l'application ou /app/

Interface de l'application

  • Sidebar (gauche) — configuration, recherche, actions, compte
  • Carte (centre) — OpenStreetMap, marqueurs, tracés d'itinéraires
  • Panneau flottant (droite) — onglets Points, Résultat, Écoles, Historique, Guide

Au premier lancement, l'onglet Guide s'ouvre automatiquement. La carte démarre vide (pas de chargement auto de l'exemple).

Mode Pickup & Delivery (recommandé)

Chaque ramassage doit être lié à une école. La liste affiche des paires domicile → école.

Consultez l'onglet Écoles pour voir le regroupement par établissement.

Configuration

  • Capacité bus — places et nombre d'élèves par ramassage
  • Fenêtres horaires — créneaux par point
  • Créneaux par défaut — ramassage 6h30–7h30, école 7h–8h
  • Routes réelles (OSRM) — distances et tracés sur le réseau routier
  • Multi-véhicules — jusqu'à 5 bus, couleurs distinctes sur la carte

Calculer et exploiter le résultat

Cliquez Calculer l'itinéraire. L'onglet Résultat affiche :

  • Résumé : distance, durée, arrêts, charge max, carburant / CO₂ estimés
  • Séquence des arrêts par véhicule
  • Tracé coloré sur la carte

Barre d'outils résultats :

  • CSV — export tableur
  • GPX — navigation GPS
  • Imprimer — feuille de route
  • Référence — comparer avec un scénario « avant / après »

Si vous êtes connecté, le calcul est aussi sauvegardé dans Historique.

L'état (points + config) est aussi persisté en localStorage entre les sessions du même navigateur.

Limitations connues

  • Serveur OSRM public — peut être lent ou indisponible ; désactiver pour Haversine
  • Google Distance Matrix — variable d'env prévue, non branchée dans le solver
  • Comparaison drag & drop vs optimal OR-Tools — réordonnancement manuel seulement
