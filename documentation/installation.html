Installation

Guide pas à pas pour installer et lancer Graphicage TER en local ou via Docker.

Prérequis

  • Python 3.10+ (testé avec Python 3.12, 64 bits)
  • pip et venv
  • Navigateur moderne (Chrome, Firefox, Edge)
  • Connexion internet (tuiles OSM, OSRM, APIs lieux)
  • Optionnel : Node.js 20+ pour les tests Playwright

1. Environnement virtuel

Linux / macOS

cd graphicage-ter-app
python3 -m venv .venv
source .venv/bin/activate

Windows (PowerShell)

python -m venv .venv
.venv\Scripts\Activate.ps1

2. Dépendances Python

pip install -r requirements.txt
PaquetUsage
Django 5Framework web, auth, admin
djangorestframeworkAPI REST
ortoolsOptimisation de tournées
psycopg + dj-database-urlPostgres Neon
gunicornServeur production (Docker)
python-dotenvVariables .env

3. Configuration (.env)

cp .env.example .env
VariableDescription
DJANGO_SECRET_KEYClé secrète (changer en production)
DJANGO_DEBUGTrue en dev, False en prod
DJANGO_ALLOWED_HOSTSHôtes autorisés
DATABASE_URLURL Postgres Neon (optionnel)
OSRM_BASE_URLServeur OSRM (défaut : public)
GOOGLE_API_KEYGéocodage Google (optionnel)
EMAIL_*SMTP pour mot de passe oublié (prod)

4. Base de données

python manage.py migrate

Sans DATABASE_URL : SQLite (db.sqlite3).

Avec Neon : ajoutez l'URL Postgres dans .env, puis migrate.

python manage.py createsuperuser   # accès admin / catalogue

5. Lancer le serveur

python manage.py runserver
Accueil : http://localhost:8000/
Application : http://localhost:8000/app/ (connexion requise)
Documentation : http://localhost:8000/documentation/

6. Docker

cp .env.example .env
docker compose up --build

Expose le port 8000 avec Gunicorn. Les migrations s'exécutent au démarrage.

7. Tests

Tests unitaires

python manage.py test routing

Utilise SQLite en mémoire (indépendamment de Neon).

Tests E2E (Playwright)

python manage.py runserver &
cd e2e && npm install && npm test

CI automatique via GitHub Actions (.github/workflows/ci.yml).

Dépannage

Port 8000 déjà utilisé

lsof -i :8000
kill <PID>
# ou
python manage.py runserver 8080

Migrations non appliquées

python manage.py migrate

Erreur OR-Tools

Python 64 bits requis. Vérifier : python -c "import struct; print(struct.calcsize('P')*8)"

pipx install requirements.txt ne fonctionne pas

Utiliser un venv et pip install -r requirements.txt.
