Graphicage TER

Application web d'optimisation de tournées de transport scolaire pour La Réunion, migrée et modernisée depuis le projet GraphicageTER.

Présentation

Graphicage TER aide à planifier les itinéraires de bus scolaires en calculant le parcours optimal entre un dépôt, les domiciles des élèves (ramassages) et les établissements scolaires (déposes).

L'application combine une landing page, un espace compte utilisateur, une carte Leaflet, un backend Django avec API REST, une base Postgres (Neon) et le moteur Google OR-Tools.

Parcours utilisateur

  1. Accueil (/) — découvrir le projet
  2. Inscription ou connexion (/compte/…)
  3. Application (/app/) — construire et optimiser une tournée

Fonctionnalités principales

🗺️ Carte interactive

Recherche de lieux, clic sur carte, import JSON, partage par URL, persistance locale.

🚌 OR-Tools

TSP et Pickup & Delivery — capacité, horaires, multi-véhicules, routage OSRM.

📊 Résultats & exports

Résumé (distance, CO₂), CSV, GPX, impression, comparaison de scénarios.

👤 Comptes

Inscription, connexion, mot de passe oublié, historique automatique des calculs.

🗄️ Base de données

Neon Postgres — catalogue de lieux, tournées sauvegardées, historique par utilisateur.

🐳 Déploiement

Docker, CI GitHub Actions, tests unitaires et Playwright E2E.

Démarrage rapide

cd graphicage-ter-app
python3 -m venv .venv
source .venv/bin/activate          # Linux / macOS
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py runserver
URLs locales
Accueil : http://localhost:8000/
Application : http://localhost:8000/app/ (après connexion)
Documentation : http://localhost:8000/documentation/
